# 排错指南

## 一、DWG→DXF 转换失败

### 症状 1：accoreconsole 日志里只有空命令提示符，DXFOUT/QUIT 都没执行

**根因**：通过 git-bash/MSYS 调用时，`/i`、`/s` 被当成路径做了转换（变成 `d:\c\...` 之类），参数失效。

**解决**：必须用 Python `subprocess.run([exe, "/i", dwg, "/s", scr])` 或 PowerShell 直接调用，绝不用 bash 命令行拼 `/i /s`。脚本 `takeoff.py` 已用 subprocess。

### 症状 2：单个文件能转，批量脚本里多个文件失败

**根因**：想在 accoreconsole 的一个脚本里连续 `OPEN` 多个 DWG —— 不支持。OPEN 后接路径会被当成新命令。

**解决**：每个 DWG 单独启动一次 accoreconsole（`/i` 传文件），脚本里只写 `DXFOUT` + `QUIT`。实测 127 个文件约 6~7 分钟，0 失败。

### 症状 3：日志报路径非法 / 中文文件名乱码

**根因**：accoreconsole 对中文路径不稳。

**解决**：prepare 阶段已把中文原图复制成 `0001.dwg` 序号名到 ASCII 工作目录；确保 `--work` 本身也是纯 ASCII 路径（如 `D:/work/.../steel_beam/batch`）。

### 症状 4：DXF 生成了但提取不到任何文字

**根因**：ezdxf 直接遍历 `doc.modelspace()` 的 TEXT/MTEXT 拿不到文字——图纸文字在块引用 INSERT 里。

**解决**：必须调用 `dwg-offline-extract` 技能的 `extract_text.py`，它会递归展开块。检查 `--extractor` 路径是否正确指向该文件。

## 二、截面提取问题

### 症状：某几根梁没有 BH 截面

先查 `--work/txt/<序号>.txt` 里有没有 `BH数字*数字` 格式文字：

- **有 BH 文字但没提取到**：检查 `--bh-re` 正则是否匹配该写法（如全角星号、空格分隔、`BH-xxx` 带横杠等），调整正则。
- **文字里根本没有 BH**：看材料表第一行是不是 `PL10*90` 之类连接板——这类梁截面非标准 H 型钢，是正常现象。经用户确认后把梁编号加进 `--excluded`。
- **txt 里文字数为 0**：说明 extract_text.py 没跑成功或 DXF 不完整，回到转换阶段排查。

### 多规格截面

同一张图出现多个 BH 候选时，脚本取第一个，并在备注写「多规格:A/B」。这类梁需人工确认到底用哪个规格。

## 三、清单核对问题

### 梁编号对不上 / 数量不对

- **清单末尾「合计」行**：脚本已自动跳过含「合计」的行；若清单格式不同导致跳过失败，检查 `--code-col` 是否指向正确的构件编号列。
- **数量比预期多/少**：确认 `--dir-glob` 是否匹配到所有楼层文件夹，以及每个文件夹的 `CAD/*.dwg` 是否齐全（布置图会被自动排除，只统计翻样图）。
- **列错位**：用只读方式打印清单前几行，核对 `--code-col`/`--qty-col`/`--weight-col`（0-based）。本项目实测为 3/4/5。

### 楼层顺序错乱

`cn_to_int()` 支持中文数字（四十八→48）。若楼层命名不含中文数字（如「F48」），脚本 `s.isdigit()` 分支不生效，会按 999 排到最后。此时改用 `--floor-re` 提取纯数字，或改 `cn_to_int` 支持新格式。

## 四、验证方法（交付前必做）

1. **编号一一对应**：对比 xlsx 清单梁编号集合与 sections.json 的 code 集合，差异应为空（排除合计行）。
2. **双路径互验**：抽 1~2 根用 CAD快速看图打开翻样图，看右上角材料表第一行 BH 规格，与程序结果比对。本项目试点 I-48GLL1-1 → BH500*400*20*35，两路径一致。
3. **重量反算**：BH 截面线密度 = `[2*b*tf + (h-2*tf)*tw] mm² × 7850 kg/m³`。如 BH500*400*20*35 = `(2*400*35 + (500-70)*20) mm² × 7850 ≈ 287.3 kg/m`。用单重÷线密度反推梁长，应与图纸量级吻合。

## 五、已知边界

- PDF 图纸无文字层，不能作为提取源。
- 只有 BH（焊接 H 型钢）规格会被自动提取；HN/HW/轧制型钢或特殊截面需另行处理。
- computer use 独立桌面是全机单例，删 GUI 任务会释放会话。需要 GUI 复核时优先用「继续任务」，不要 delete_task 重建。
